# Logo assets

SVG and 512 × 512 transparent PNG artwork from the libtmux logo kit,
revision `555f60aff5341d8ba59c7466eb9abb537084c98d`.

Library marks use the cog, workspace marks the tiled tmuxp base, and MCP
marks the Model Context Protocol symbol. Language colors follow
[GitHub Linguist](https://github.com/github-linguist/linguist/blob/538da05f034fa5c83bd81df128d144e208898da3/lib/linguist/languages.yml).
The source libtmux and tmuxp artwork belongs to the project owner. The MCP
symbol comes from the [upstream logo](https://github.com/modelcontextprotocol/modelcontextprotocol/blob/088176704a4e8f20e7f1d237de1de8484aa412fd/docs/logo/light.svg).

Package-specific artwork sits beside its README where the package format
supports it. `.github/social-preview.png` is the cog sharing card, ready to
upload under the repository's **Settings → Social preview**.
